# External Dependencies

Streaming Radio addition (6 November 2026): ZXing Core 3.5.4, Apache-2.0,
https://github.com/zxing/zxing. Used only to encode pairing QR codes locally.
The Apache license text is bundled as legal/apache-2.0.txt.

Optional phone transfer, when configured, uses Firebase Authentication
(anonymous technical identities), Hosting and Realtime Database. Its public
project configuration/API key is not a user password. The phone Cast flavor
adds Google's Cast Sender SDK. It sends anonymous encrypted Cast interaction
telemetry as described in the privacy policy; the app has no separate
analytics SDK.

The Cast-enabled phone variant uses the Apache 2.0 option for covered
Streaming Radio and Twinsen Radio code. The Google Cast SDK remains under
Google's separate terms. Keep the upstream license texts and notices.
The dependency summary below describes the original non-Cast app dependencies.


The original app dependencies below are open source. The phone-only Cast SDK
is an additional Google Play services dependency and is excluded from that
summary; its terms require separate distribution review.

## Data and network services

At runtime, the app queries free, public APIs — none of which require a
key or registration:

* **[radio-browser.info](https://www.radio-browser.info/)** — a station
  directory for searches outside the built-in list (`RadioBrowser.kt`).
* **iTunes Search API**, **MusicBrainz**, and **Cover Art Archive** — track
  cover art (`CoverArtLookup.kt`).

See [Legal disclaimers in README.md](README.md#legal-disclaimers) regarding
station logos and the audio streams themselves.

The rounded Settings and refresh artwork glyphs derive from Lucide Icons,
ISC license, copyright Lucide Icons and Contributors. Full GPLv3, Apache-2.0
