# README gallery provenance

The five VR01-F through VR05-F images are AI-assisted screenshot-style reconstruction mocks, approved by the user on 9 November 2026. They use owner-supplied photographs of Streaming Radio on a 2023 Volvo XC90 running Android 13 as layout references. They are not photographs, emulator captures, or verified screenshots from the released app.

- screenshots/volvo-mocks/VR01-F.png: Player with fictional track artwork.
- screenshots/volvo-mocks/VR02-F.png: Native station list.
- screenshots/volvo-mocks/VR03-F.png: Playlist station management.
- screenshots/volvo-mocks/VR04-F.png: Settings.
- screenshots/volvo-mocks/VR05-F.png: Station-image picker.

The mocks preserve the reference UI structure while removing photographic artifacts and substituting fictional station/artist/track examples, original sample artwork, reserved example.com URLs and a generic profile icon. Personal avatar initials, personal hostnames, real station logos and the photographed commercial album art are excluded. Native system dock icons are illustrative references to the vehicle UI, not app features or endorsements.

The original six generic API33 screenshots were removed because their host layout did not represent the Volvo. Owner photos are not included in this replacement gallery. Historical assets elsewhere are not part of the README gallery. No artwork or station list shown is a bundled catalog. Actual layout, control availability and scale depend on the vehicle host and app version; these illustrations do not establish current-build or hardware acceptance.
